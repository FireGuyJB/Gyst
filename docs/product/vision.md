# Vision

## The problem

Big goals ("run a marathon", "launch my business") are motivating but vague.
It's hard to know what to do *today* to move toward them, so people stall.

## The idea

Gyst ("get your stuff together") uses the structure of a **Harada chart**, a
goal-setting method made famous by athletes like Shohei Ohtani:

```
            1 primary goal
                  │
      ┌───────────┼───────────┐   8 supporting goals
      │           │           │   (the pillars that make the primary goal happen)
   ┌──┼──┐     ┌──┼──┐     ┌──┼──┐
   tasks…      tasks…      tasks…  8 tasks per supporting goal = 64 tasks
```

Then Gyst goes a step further than a paper chart: the **64 tasks become a
checklist and a calendar**, so the user builds routines and always knows what
to do today.

## Who it's for

People with a meaningful long-term goal who want structure and daily
accountability, not just a to-do list.

## What success looks like

- A user can set up a full goal → 8 → 64 chart without friction.
- Each day, the user sees which tasks are scheduled and checks them off.
- Over time, the user can see progress toward each supporting goal and the
  primary goal.
